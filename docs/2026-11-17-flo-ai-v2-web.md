# Flo AI v2: admin web handoff (2026-11-17)

Contract: `roundflow-backend/docs/handoff/frontend/2026-11-17-flo-ai-v2-frontend-contract.md`. Built against that contract with MSW fixtures; not yet run against the v2 backend.

## What changed

- **Charts.** `ChartBlock.tsx`: inline SVG bar and line charts, no new dependency. Horizontal bars with the label above each bar so long labels fit; lines support up to 3 series with thinned x ticks. Colours are existing token CSS variables. Values and axis labels go through `formatFloValue`. Handles empty, one row, negative values (zero baseline), nulls and non-numeric cells. Accessible: the drawing is `aria-hidden`; a `role="img"` wrapper has a summary label (series, highest, lowest) and a visually hidden data table is the fallback, with a legend for more than one series. Fits phone width with no page-level horizontal scroll. A bad `kind` or missing rows, series or x falls through to the existing unknown-block handling and is ignored.
- **Feedback.** `MessageFeedback.tsx`: thumbs up and down under each finished answer, `aria-pressed`, optimistic with rollback and an error toast on failure. Thumbs-down opens an optional comment (500 chars, counter) sent as a second POST. Hidden while streaming, on declines, errors, malformed answers, and when there is no message id. Reads `rating` from the final message.
- **Morning briefing.** A prominent button on the welcome screen sends the fixed prompt "Give me my morning briefing".
- **CSV export.** "Export CSV" on every table (`features/flo/lib/csv.ts`): proper escaping, cells starting with `= + - @`, tab or CR get a leading single quote (formula-injection guard), numbers stay plain so currency exports as numbers, UTF-8 BOM, CRLF, totals row, filename `<title-slug>-YYYY-MM-DD.csv`, Blob download.
- **Links.** `BlockLink.tsx` is shared by table, cards and chart blocks (reuses `links.ts` and the existing "Open <screen>" copy). `CardsBlock` now renders `link`.
- **API and types.** `flo.api.ts` gains `FloChartBlock`, `FloRating`, `rating?` on messages, `link?` on cards, and `floApi.feedback(id, body)`. Still hand-typed with `// TODO(types.gen)`.

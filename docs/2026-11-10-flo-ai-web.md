## Behaviour

- Status lines fill live ("Checking…" then "Checked N data sources"). Sentences type in; tables and cards fade in whole. The view follows the answer only while the user is at the bottom; otherwise a "Jump to latest" button appears.
- `done` replaces the streamed state with the persisted message. A dropped stream is recovered once via GET by matching the assistant message `id` to `start.messageId`; otherwise a retryable error is shown.
- `declined` renders a calm notice with the fixed text and suggestion chips. Unverified sentences get a small marker and the answer shows a notice.
- Plain text only: no `dangerouslySetInnerHTML`, no model URLs. Links honour only the `round`/`roundId`, `date` and `visitId` params, and only when they pass the existing id and date format checks; other screens link to the bare route.
- Tables are real tables (caption, `th scope="col"`, `tfoot` totals). Statuses go through a polite live region; sentence deltas are not announced.
- Errors map the codes in the contract. A 409 `FLO_REQUEST_IN_PROGRESS` just shows its message (no automatic wait). Persisted ERROR or ABORTED messages show generic retry copy.
